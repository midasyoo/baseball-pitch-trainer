# ⚾ Baseball Pitch Trainer — 야구 투구 트레이닝 3D 시뮬레이터

아이의 야구 학습을 위한 웹 기반 3D 투구 학습 프로그램.
`야구 투구 트레이닝 3D 시뮬레이터 SW 상세설계서(SDD) v1.0` 기반 Phase 1 MVP 구현.

## 실행 방법

### PC
`index.html`을 브라우저(Chrome/Edge)에서 더블클릭으로 열면 끝.
서버·DB·로그인 불필요. (Three.js·모델·AI를 CDN에서 불러오므로 인터넷 연결 필요)

### 아이폰/스마트폰 (반응형 레이아웃 내장)
아이폰은 로컬 HTML 파일을 직접 실행할 수 없으므로 웹 주소로 접속해야 한다. 두 가지 방법:

**방법 A — 집 와이파이 (즉시)**
1. PC에서 이 폴더를 열고 `node serve.js` 실행
2. 화면에 표시되는 `http://192.168.x.x:8770` 주소를 아이폰 Safari에 입력 (PC와 같은 와이파이)
3. Safari 공유 버튼 → **"홈 화면에 추가"** → 앱 아이콘처럼 사용

**방법 B — GitHub Pages (어디서나, 영구 주소)**
1. github.com 가입 → 새 저장소 생성(공개) → `index.html` 업로드
2. Settings → Pages → Branch: main 선택 → 저장
3. 몇 분 후 `https://아이디.github.io/저장소명/` 주소 생성 → 아이폰 북마크/홈 화면 추가

모바일에서는 구종 목록이 상단 가로 스크롤 칩으로, 정보/연습 패널이 3D 화면 아래로 배치된다.
📷 카메라 그립 체크는 폰에서 버튼을 누르면 카메라가 바로 열린다.

## 구성

### 상단 2개 모드
| 모드 | 내용 |
|------|------|
| 🧠 **원리 이해** | ①그립 → ②릴리스 → ③회전 → ④투구 자세 → ⑤궤적 5단계 3D 학습 + "왜 이렇게 움직일까?" 원리 설명 |
| ✋ **실제 연습** | 3D 그립을 보며 실제 공으로 따라 하기 — 연습 순서, 📷 카메라 그립 체크(AI 손 인식), YES/NO 자가진단, 점수/피드백, 청소년 안전 수칙 |

### 📷 카메라 그립 체크 (SDD Phase 3 초기 구현)

- 실제 공을 쥔 손 사진을 찍어 올리면 MediaPipe Hand Landmarker(Google, CDN 로드)가 21개 손 관절을 인식.
- 사진 위에 관절을 색상별(검지 빨강·중지 파랑·약지 초록·새끼 보라·엄지 노랑 = 3D 마커와 동일)로 표시.
- 구종별 규칙으로 그립 점검: 검지·중지 간격(포심↔스플리터↔포크볼), 엄지·검지 서클(체인지업),
  중지·약지 벌림(벌칸), 검지 구부림(너클 커브·너클볼) 등 → ✓/△ 교정 안내.
- 첫 사용 시 AI 모델 다운로드(~7MB)로 10~20초 소요. 사진은 기기 밖으로 전송되지 않음(브라우저 내 처리).
- 정확도 한계: 2D 사진 휴리스틱이므로 참고용. 공 인식·3D 정합은 향후 과제.

### 구현된 14개 구종 (Phase 1 + Phase 2 완성)
- 패스트볼: 포심 · 투심 · 커터 · 싱커
- 변화구: 슬라이더 · 스위퍼 · 커브볼 · 너클 커브 · 포크볼 · 스플리터
- 오프스피드: 서클 체인지업 · 벌칸 체인지업
- 특수 구종: 너클볼 · 스크류볼 (관찰·원리 이해 전용 — 안전 경고 포함)

각 구종마다: 3D 실밥(파라메트릭 곡선) · 리깅된 리얼 핸드 그립 + 접촉점 마커 · 릴리스 슬로모션(엄지→손끝 분리 타이밍) ·
회전축/회전방향/RPM · 투구 자세 6단계(P0 SET~P5 FOLLOW THROUGH) 스켈레톤 애니메이션 ·
베지어 궤적 + 스트라이크 존 · 자가진단 4문항.

### 리얼 핸드 (리깅 모델 + 자동 포징)

- 손 모델: [WebXR Input Profiles generic-hand](https://github.com/immersive-web/webxr-input-profiles) (Apache-2.0) — 스킨드 메시 + 25관절 뼈대. CDN 로드, 백업 사본은 `assets/right-hand.glb`.
- WebXR용 GLB는 관절이 평면 계층이라 로드 후 해부학적 체인(손목→마디→손끝)으로 재부모화하여 FK를 활성화한다.
- 그립 포즈는 구종 데이터의 **접촉점만으로 자동 생성**: 접촉점을 향해 공 표면을 감는 측지선을 따라 뼈 길이만큼 행진해 관절 목표를 만들고 각 뼈를 조준(aim)한다. 새 구종을 추가해도 손 포즈 작업이 필요 없다.
- 릴리스 애니메이션은 뼈 회전을 그립 포즈 → 펴진 손으로 슬러프 보간(엄지 먼저, 손끝 나중).
- GLB 로드 실패(오프라인) 시 절차적 손으로 자동 폴백.
- 진단: `index.html#debug=1` 로 열면 관절 월드좌표와 솔버 로그를 DOM에 덤프.

### 릴리스 손가락 정밀 연출

- 구종 데이터 `release.fingers`에 손가락별 역할·타이밍 정의: `snap`(긁으며 튕기기) ·
  `press`(끝까지 눌러주기) · `hold`(꽉 잡고 지지) · `release`(먼저 놓아주기) · `loose`(힘 빼고 걸치기).
- 그립보다 깊이 파고든 "프레스 포즈"를 추가 계산해 누르기↔그립↔펴기 3단계로 뼈를 블렌딩.
- 릴리스 모드에서 손끝마다 색상 궤적(trail)과 동작 순간 방향 화살표(누르기=공 안쪽, 긁기=실제 이동 방향) 표시.
- 좌측 하단 범례를 클릭하면 해당 손가락을 0.25x 슬로모션으로 확대 추적(포커스 모드).

### 리얼 인체 투수 (투구 자세)

- 모델: three.js 공식 Xbot(믹사모 리그, MIT). CDN 로드, 백업 `assets/xbot.glb`.
- 투구 6단계 키프레임(관절 위치)을 각 뼈에 조준(aim) 리타겟팅 — 골반은 척추 정렬 + 무릎 방향 트위스트.
- 로드 실패 시 볼륨 피규어(유니폼·모자·글러브)로 폴백.
- 진단: `#debug=2`(리타겟 뼈 좌표 덤프), `#t=0.7`(시점 고정), `#cam=x,y,z,tx,ty,tz`(카메라 고정).

## 새 구종 추가 방법 (SDD 원칙 3·4: 엔진과 데이터 분리)

엔진 코드는 수정하지 않는다. `index.html`의 `PITCHES` 객체에
기존 구종과 같은 필드로 데이터만 추가하면 그립(IK 자동 포징)·릴리스(손가락 역할 연출)·회전·자세·궤적·자가진단이 전부 자동 동작한다.

```js
sinker: {
  id:'sinker', phase:1, nameKo:'싱커', nameEn:'Sinker', family:'FASTBALL', difficulty:3,
  summary:'...', principle:'...',
  grip:{ ballRotation:[0,0,0], fingers:{ index:{pos:[x,y,z],main:true}, ... }, note:'...' },
  release:{ thumbTiming:0.62, fingerTiming:0.85, note:'...' },
  spin:{ axis:[x,y,z], speed:0.9, rpm:2100, label:'...', note:'...' },
  motion:{ armSlot:58, releaseHeight:0.97 },
  trajectory:{ start:[0,1.8,0.5], c1:[...], c2:[...], end:[...], speedFactor:0.95, note:'...' },
  coaching:[ {q:'...', correct:'YES', fb:'...'}, ... ],
  practice:{ routine:['...', ...] }
}
```

## 딥링크 (공유/테스트용)

## 재생 컨트롤

재생/일시정지/처음부터 · 슬로모션 0.25x / 0.5x / 1x · 카메라: 그립/투수/포수/타자 시점 · 마우스 드래그 360° 회전

## 안전 안내

청소년 학습용 프로그램으로, 과도한 손목 비틀기나 변화구 반복 연습을 유도하지 않으며
자가진단 점수는 의료적·전문적 평가가 아닌 학습 참고용이다. 실전 연습은 지도자와 함께.
